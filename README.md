# Libft

## Description

Libft is a custom C library that recreates standard C functions and introduces additional utilities. It covers string manipulation, memory management, conversions, and linked lists.

## Instructions

Compile the library:

```
make
```

Available commands:

- `make clean` — removes object files.
- `make fclean` — removes object files and the library.
- `make re` — rebuilds the library.

To use Libft:

```cpp
#include "libft.h"
```

## Library Contents

- **Libc Functions:** Reimplementations of standard C library functions.
- **Additional Functions:** String manipulation, conversions, and file descriptor output.
- **Linked List:** Singly linked list operations, including node creation, insertion, deletion, and iteration.
